# Nagatamen Chapter Website

Test rebuild of the Nagatamen Chapter website for GitHub Pages.

## Structure
- `index.html` — homepage
- `styles.css` — site design
- `site.js` — event/post rendering
- `posts/` — future Drumbeat content

The first build uses sample event data. The next step is connecting the Nagatamen Google Calendar so upcoming event cards are generated automatically.

Designed to remain a lightweight static site that can be maintained through GitHub and ChatGPT.
